# Zo zet je dit op GitHub

1. Pak Balkonboeman_GitHub_opzet.zip uit op je computer.
2. Schrijf je eigen teksten in README.md; vervang de WRITE-velden. Gebruik WERKNOTITIES_NL.md als feitencheck.
3. Open https://github.com/JoepH24/balkonboeman (de hoofdpagina, niet de README-bestandweergave).
4. Bewaar eerst de bestaande README; die kon niet worden uitgelezen en is niet verwerkt in dit pakket.
5. Klik Add file → Upload files.
6. Sleep README.md en de mappen images en evidence uit de uitgepakte map in het uploadvak. Upload NIET de ZIP en NIET de hele bovenliggende map: README.md moet direct in de repository staan.
7. Noteer als commitomschrijving bijvoorbeeld: Add camera experiment draft and evidence.
8. Klik Commit changes. Dit vervangt de README op main: doe dit pas wanneer je de inhoud hebt gecontroleerd.
9. Open de repositorypagina. Controleer dat alle afbeeldingen zichtbaar zijn en de videolink opent.
10. De Nederlandse notities en deze uploadhulp hoeven niet online. Geef de docent de repositorylink wanneer je eigen manualtekst klaar is.

GitHub kan het MOV-bestand als download tonen in plaats van als afspeelbare video; de link blijft bruikbaar.

## Eerst uit Colab bewaren

Download best.pt, last.pt en results.csv via het mapicoon links. Zoek /content/yolov5-swift/runs/train/balkonboeman_test4/. Modelbestanden staan in weights/. Rechtsklik elk bestand → Download. Deze echte bestanden zijn niet in het pakket omdat ze alleen in jouw Colab staan.
